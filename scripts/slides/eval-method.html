How the harness measures

It scores the real production agents — imported, not re-implemented — against a 40-case labelled synthetic corpus
Input
40 synthetic cases
deterministic, seed 7 — bank confirmation · register · payslips per event
→
Real pipeline agents
Classifier · EventLinker · Validator · PnLAgent
imported from jobs/ & endpoints/ — the deployed code, not a copy
→
Scored vs ground truth
classification · field · fusion · validation
numbers ≤1¢ or ≤0.5% · dates exact · booleans exact
perfect_extractor → the ceiling
returns exactly the fields the current prompt emits — so the ceiling is the real product's reachable best, not an idealised schema.
degraded_extractor → sensitivity
±6% numeric noise, dropped fields, generic doc types — proves the metrics actually move, and the classifier earns its place.
⚖ Two truths, kept separate on purpose
The figure truth (what is the cost?) is scored apart from the validation truth (do the books reconcile?) — so a validation bug can never hide behind a correct number.
